Sync with GitHub

Notes are saved as Markdown files in a GitHub repository, so every PC you connect shows the same notes.

  1. Open GitHub → New fine-grained token.
  2. Repository access: Only select repositories → your notes repo.
  3. Permissions → Repository → Contents: Read and write.
  4. Generate, copy the token (github_pat_…) and paste it above. Do this once on each PC.
